 Relatório de Validação

1. Objetivo

Este documento apresenta os testes planejados para validar o funcionamento do sistema PainelFila Escolar. Os testes têm como objetivo verificar se as principais funções do sistema atendem aos requisitos definidos no projeto. 

2. Testes Funcionais

Teste 01 – Retirada de senha

Objetivo: Verificar se o aluno consegue retirar uma senha pelo sistema.

Procedimento:
1. Acessar o sistema.
2. Selecionar a opção de retirada de senha.
3. Solicitar uma nova senha.

Resultado esperado: O sistema deve gerar uma senha e disponibilizá-la para o aluno.

Resultado obtido: Pendente de execução.

---

Teste 02 – Geração das senhas em ordem

Objetivo: Verificar se as senhas são geradas seguindo uma sequência correta.

Procedimento:
1. Solicitar uma senha.
2. Solicitar uma segunda senha.
3. Comparar a sequência das senhas geradas.

Resultado esperado: As senhas devem ser geradas em ordem, sem repetição ou quebra da sequência.

Resultado obtido: Pendente de execução.

Teste 03 – Organização da fila de espera

Objetivo: Verificar se as senhas aguardando atendimento permanecem organizadas na fila.

Procedimento:
1. Inserir diferentes senhas na fila.
2. Consultar a fila de espera.
3. Verificar a ordem das senhas.

Resultado esperado: As senhas devem permanecer organizadas de acordo com a ordem de chegada.

Resultado obtido: Pendente de execução.

---

Teste 04 – Chamada da senha

Objetivo: Verificar se uma senha pode ser chamada para atendimento.

Procedimento:
1. Acessar a função de chamada.
2. Selecionar a próxima senha da fila.
3. Realizar a chamada.

Resultado esperado: A senha chamada deve ser apresentada corretamente para o usuário.

Resultado obtido: Pendente de execução.


Teste 05 – Exibição da senha no painel

Objetivo: Verificar se a senha chamada aparece corretamente no painel de atendimento.

Procedimento:
1. Realizar uma chamada.
2. Observar a tela do painel.
3. Conferir a senha apresentada.

Resultado esperado: A senha chamada deve aparecer de forma clara no painel.

Resultado obtido: Pendente de execução.

Teste 06 – Retirada da senha da fila

Objetivo: Verificar se a senha chamada deixa de aparecer como aguardando atendimento.

Procedimento:
1. Realizar uma chamada.
2. Consultar novamente a fila de espera.

Resultado esperado: A senha chamada não deve continuar na lista de senhas aguardando atendimento.

Resultado obtido: Pendente de execução.

 3. Validação dos Requisitos

| Requisito | Teste relacionado | Situação |
|---|---|---|
| Permitir retirada de senha | Teste 01 | Pendente |
| Gerar senhas em ordem | Teste 02 | Pendente |
| Organizar a fila de espera | Teste 03 | Pendente |
| Realizar chamada de senha | Teste 04 | Pendente |
| Exibir senha chamada no painel | Teste 05 | Pendente |
| Retirar senha chamada da fila | Teste 06 | Pendente |

4. Considerações Finais

Os testes apresentados neste documento foram definidos para verificar as principais funcionalidades do PainelFila Escolar.

A execução prática dos testes será realizada durante a etapa de validação do projeto. Após a execução, os resultados serão atualizados neste documento, registrando quais funcionalidades foram aprovadas e quais precisam de ajustes.
