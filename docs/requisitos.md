PainelFila Escolar

1. Descrição do Projeto

O PainelFila Escolar é uma solução desenvolvida para organizar o atendimento dos alunos na direção da escola.

O sistema utiliza um painel eletrônico e um dispositivo para retirada de senhas. Dessa forma, os alunos podem aguardar o atendimento sem precisar utilizar celulares.

A direção poderá chamar cada senha pelo painel, mantendo a ordem dos atendimentos e reduzindo a aglomeração no local.

2. Problema

Um problema comum na escola é a formação de filas e a aglomeração de alunos na direção, principalmente durante o intervalo e nos horários de maior movimento.

Essa situação pode causar:

- Demora no atendimento;
- Aglomeração de alunos;
- Desorganização da fila;
- Dificuldade para manter a ordem dos atendimentos;
- Alunos esperando por muito tempo.

3. Solução

O PainelFila Escolar funcionará por meio de um sistema de senhas.

Ao chegar à direção, o aluno retirará uma senha utilizando um botão ou teclado disponível no local.

Depois, deverá aguardar o atendimento em um espaço indicado.

A direção poderá chamar a próxima senha utilizando um computador ou painel de controle. O número chamado aparecerá em um painel eletrônico visível aos alunos.

Por exemplo:

SENHA A023 → DIRIGIR-SE À DIREÇÃO

Assim, os alunos não precisam utilizar celulares para acompanhar a fila.

4. Público-alvo

- Alunos;
- Direção da escola;
- Funcionários responsáveis pelo atendimento.

5. Objetivo Geral

Desenvolver uma solução tecnológica para organizar o atendimento dos alunos na direção, reduzindo filas e aglomerações no ambiente escolar.

6. Objetivos Específicos

- Organizar a ordem de atendimento;
- Criar um sistema de retirada de senhas;
- Exibir a senha chamada em um painel eletrônico;
- Diminuir a aglomeração na direção;
- Facilitar o controle dos atendimentos;
- Desenvolver uma solução que não dependa do uso de celulares pelos alunos.

7. Funcionamento do Sistema

Para o aluno

- Retirar uma senha no dispositivo disponível na direção;
- Aguardar no local indicado;
- Observar o painel eletrônico;
- Dirigir-se à direção quando sua senha for chamada.

Para a direção

- Visualizar a fila de senhas;
- Chamar a próxima senha;
- Repetir uma senha caso o aluno não tenha percebido;
- Finalizar o atendimento;
- Passar para a próxima senha.

8. Benefícios

O PainelFila Escolar poderá tornar o atendimento mais organizado e diminuir a quantidade de alunos esperando em frente à direção.

Além disso, a solução não exige que os alunos tenham ou utilizem celulares, tornando o sistema adequado para o ambiente escolar.

9. Tecnologias

O projeto poderá utilizar:

- HTML;
- CSS;
- JavaScript;
- GitHub;
- Computador;
- Painel eletrônico ou monitor;
- Teclado ou botão para retirada de senha;
- Impressora térmica, caso seja utilizada para imprimir as senhas.

10. Resultado Esperado

Espera-se que o PainelFila Escolar organize o atendimento da direção, reduza as filas físicas e facilite o controle dos alunos que aguardam atendimento.

A solução deverá funcionar de maneira simples, rápida e sem depender do uso de celulares pelos estudantes.

Documento de Requisitos

Requisitos Funcionais

 O sistema deve permitir a retirada de uma senha pelo aluno.

 O sistema deve gerar senhas em ordem.

 O sistema deve registrar as senhas que estão aguardando atendimento.

 O sistema deve permitir que a direção visualize a fila de atendimento.

 O sistema deve permitir que a direção chame a próxima senha.

 O sistema deve exibir a senha chamada no painel eletrônico.

 O sistema deve permitir repetir a senha chamada.

 O sistema deve permitir finalizar um atendimento e chamar a próxima senha.

Requisitos Não Funcionais

 O sistema deve ser simples e fácil de utilizar.

 O painel deve apresentar a senha de maneira clara e visível.

 O sistema deve funcionar sem que os alunos precisem utilizar celulares.

 O sistema deve apresentar as senhas em ordem de atendimento.

 O sistema deve responder rapidamente aos comandos realizados pela direção.

 O sistema deve possuir uma interface adequada para utilização no ambiente escolar.


Conclusão

O PainelFila Escolar apresenta uma solução tecnológica para um problema presente no ambiente escolar: a formação de filas e a aglomeração de alunos na direção.

Por meio de um sistema de senhas e um painel eletrônico, será possível organizar os atendimentos, melhorar o fluxo de alunos e reduzir o tempo de espera.

A solução também respeita a regra de não utilização de celulares na escola, pois todo o processo pode ser realizado por equipamentos instalados no próprio ambiente escolar.
