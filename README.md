PainelFila Escolar

 Sobre o projeto

O PainelFila Escolar é um sistema desenvolvido para organizar o atendimento e o controle de filas no ambiente escolar.

Objetivo

O projeto tem como objetivo facilitar a retirada de senhas pelos alunos e ajudar a direção no controle e na chamada das senhas.

 Funcionalidades

- Retirada de senha
- Geração de senhas em ordem
- Organização da fila de espera
- Chamada de senha
- Exibição da senha chamada no painel
- Registro das senhas atendidas

 Tecnologias

- HTML
- CSS
- JavaScript
- GitHub
- Trello
- Draw.io
